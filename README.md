# AI Commerce 🛍️

אתר e-commerce מודרני עם תכונות AI - בנוי ב-HTML, CSS ו-JavaScript טהורים.

## הפעלה

פתחו את `index.html` בדפדפן, או הריצו שרת מקומי:

```bash
python3 -m http.server 8000
```

ואז גשו ל-http://localhost:8000

## תכונות

- 🎨 עיצוב מודרני Dark Mode עם Gradients
- 🛒 עגלת קניות עם שמירה ב-localStorage
- 💬 צ'אט AI עם תגובות חכמות
- 🔍 סינון מוצרים לפי קטגוריה
- ✨ המלצות AI מסומנות
- 📱 רספונסיבי מלא
- 🌐 תמיכה מלאה ב-RTL (עברית)

## מבנה

- `index.html` — מבנה הדף
- `styles.css` — עיצוב
- `app.js` — לוגיקה (מוצרים, עגלה, צ'אט)
